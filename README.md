# E-Commerce Sales Analysis (PowerBI Dashboard))

## Purpose
Visualizes user purchase behaviors, spending patterns, and regional sales to turn raw transactional data into actionable business insights.
Utilizing  foundational skills of data analysis within the tool.

## Key Insights Visualized
* **Profitability:** Tracks monthly net profit trends to identify peak seasons and margin drops.
* **Product Performance:** Highlights top-performing sub-categories (Printers, Bookcases, Sarees).
* **Category Share:** Displays volume distribution across Clothing (63%), Electronics (21%), and Furniture (17%).
* **Geography:** Maps sales performance across key states (Maharashtra, MP, UP, Delhi).
* **Payment Modes:** Breaks down transaction types, led by Cash on Delivery (COD) and UPI.
